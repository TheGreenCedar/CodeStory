# Handoff evidence

Read the [engineering handoff](../018-investigation-handoff.md) first. These are
small, sanitized development records, not formal acceptance or exact raw receipts.

- `v495-question-1.json` / `v495-question-2.json`: unchanged ordinary question text,
  pinned public source commit; machine root substituted with `<CRON_ROOT>`.
- `v495-baseline-*.packet.json`: actual installed 66443951… baseline packets.
- `v495-continuation-*.packet.json`: preserved failed first and successful second
  baseline follow-ups. No new candidate result is represented.
- `v495-reader-search-1.public.json` and the three `*-public.json` snippet files:
  decisive ordinary follow-up discovery/configuration/test-body delivery.
- The six other `v495-reader-*.public.json` / `*-public.json` helper and bounds
  results: all remaining public source/search deliveries cited by the frozen
  baseline answers, including the constructor-test search gap.
- `baseline-reader-*`: frozen baseline answers, coverage assessment and exhaustive
  read inventory. The baseline procedure's incidental metadata exposure is
  disclosed; these files contain no withheld reference answer.
- `commands-and-results.json`: exact sanitized saved argv, recorded results and
  output hashes; absent receipts are marked unexecuted. Browser historical passes
  do not qualify its later missing-frame correction.
- `source-bindings.json`: 109 selected serving-source/manifests bindings and four
  expected WIP changes, not a complete build attestation. The remote Windows
  merge and handoff additions are described separately in the main document.
- `sanitization-manifest.json`: original/published SHA-256 and byte counts for
  copied records; only machine-root substitutions were applied.
- `CRON-LICENSE.txt`: attribution/license for public source excerpts.

No raw caches, model assets, executable packages, private settings, chat, or gold
references are included. Old generation/cursor IDs are historical evidence;
obtain new actual product actions when reproducing on a different publication.
